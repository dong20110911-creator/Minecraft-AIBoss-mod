# 调用者 · 协议裂隙

AI 拟人 Boss 生存冒险模组完整设计 v0.3

2026-11-13 | 统一执行版 | 设计提案，尚未实机验证

# 01 统一定位与本版决策

**项目代号：调用者 · 协议裂隙。** 面向原版生存玩家的五角色遗迹 Boss 模组。玩家是使用 AI 的“调用者”，在世界中探索五处推演域，学习战斗、夺取权限，把 Boss 的代表机制转化为自己的装备能力。

本版将 v0.1 主设计、v0.2 生存补充和最新意见重新整合为一份执行基准。旧稿仅作历史参考；本版覆盖其阶段、场地、饰品栏、动作适配和开发交接决策。当前交付是规格与资料包，尚未建立可运行模组工程，所有数值均为首轮测试起点。

| 决策 | 本版确定内容 |
| --- | --- |
| 首发平台 | Minecraft Java 1.20.1 / Forge 47.x / Java 17；未来版本单独移植 |
| 角色与外观 | DeepSeek、GPT、Claude、Gemini、Grok；采用用户提供的五张社区参考图 |
| 实体与模型 | 独立模组实体、碰撞与动画；身高约 2.20-2.45 格；不使用盔甲架代替 |
| 战斗骨架 | 普攻、连招、格挡、反击窗口；每位三阶段，机制可读、可破、有代价 |
| 世界表现 | 异象、外围敌人、固定祭坛、主战场；不安排居家日常或好感系统 |
| 成长与装备 | 原版材料入门 → 印记过渡 → 角色武器 / 饰品 → 精通强化 |
| 动作与饰品 | 原生战斗可独立玩；Curios 提供饰品槽；动作模组采用互斥适配路线 |
| 开发规模 | 先做一位 Boss 的完整闭环，再逐位扩展；不同时铺开五套半成品 |

**完成版的内容边界。** 五处地表遗迹、五位 Boss、两种入门武器路线、五把角色武器、五件饰品、五件单部位护具、五种消耗品；外围小兵分批补齐。不做新维度、职业树、随机词条海、联网聊天 AI 或实时模型调用。

**体验目标。** 普通玩家穿铁甲、拿远征武器与盾，即可学习第一战；单人熟练战约 3-5 分钟。压迫感来自空间、节奏、有限但危险的能力与阶段演出，不依靠无提示秒杀、超大血量或全屏粒子。

**版本说明。** 1.21.11 作为用户提出的未来候选，不承诺与 1.20.1 共用发行包或全部依赖；先完成首发，再核查目标版本的加载器、API 和依赖支持。

# 02 世界观：玩家就是调用者

一次没有结束的调用，把“答案”带进了方块世界。原本应停留在界面里的推演，在五处地点获得了形体；每个推演域都把一种回答习惯放大成了真实规则。玩家手中的空白载体保留着调用者身份，也因此有资格进入这些领域。

五位角色是不同协议的具象化身，各自坚持自己的解题方式。玩家要在实战中证明：可以接受帮助，也能识别委托失控、冗余过量、规则束缚、思路偏离与越界挑战。战斗胜利意味着取得一部分可控权限，不意味着成为她们的主人或让角色改做生活 NPC。

| 对象 | 世界中的含义 | 对应玩法 |
| --- | --- | --- |
| 调用者 | 玩家自己的身份，没有固定出身剧情 | 原版开局；任意探索顺序；保留建造与采集 |
| 调用载体 | 把意图写入世界的器具 | 入门武器、工作台与召唤凭证 |
| 推演域 | 一种思维方式变成可触碰的空间 | 固定遗迹、场地机关、领域规则 |
| 额度 | 可用能力的预算，并非真实账号余额 | 专注值、技能冷却、额度重置卡 |
| 上下文 | 玩家已经取得、能被世界记住的经验 | 图鉴、首次胜利、精通挑战与进度 |
| 权限碎片 | 完成一次对抗后取得的能力痕迹 | 锻造角色装备与升级 |

**故事怎样呈现。** 初制远征工具时出现一页短引导；到遗迹外缘看到异象与刻文；开战前一句回应；阶段切换以动作与场景反馈讲述；胜利后取得一条图鉴记录。每次首次信息不超过约 60 字，允许跳过，不堵住操作。

**贯穿主线。** “请求已发送，后果由你接住。” 玩家从依赖工具到理解并掌控规则。收集五枚初胜印记可锻造纪念物“调用者凭证”，获得外观与图鉴收束；首发不隐藏第六个终极 Boss，也不把毕业装备强制锁在五连战后。

**角色服务于 IP 的方式。** DeepSeek 的转包与干饭成为资源调度；GPT 的周全成为有限后手；Claude 的礼貌与约束成为双向契约；Gemini 的发散成为未完工程；Grok 的挑衅成为公开下注。这些是本模组选用的社区二创演绎，不宣称是公司官方人格或全网唯一设定。

**无需外部服务。** “调用”“额度”“封号”等都是离线世界里的拟物化表达。玩家安装模组即可游玩，无需 AI 账号、API 密钥或按战斗付费；角色台词采用预写事件表。

# 03 五座遗迹与探索压迫感

每处遗迹分为远景异象、外围废墟与主祭坛三层。外围有补给、提示与少量敌人，主场地才承载完整 Boss 机制。首发全部使用原版维度与主要原版方块，不另建新维度。

| 角色 / 推演域 | 地形与远景 | 主战场与开战反馈 |
| --- | --- | --- |
| DeepSeek · 深海调度台 | 深海生物群系中的小岛；断裂鲸形石脊、向上回流的蓝色信标 | 半径 24 格陆地环台；海下任务柱依次亮起，中央投影压低，红蓝委托点苏醒 |
| GPT · 冗余穹庭 | 高原或山脊；三层不完全重合的门环，远看像同一结构不断复制 | 半径 26 格；三枚备用节点依次闭合，退路仍可见，脚下显出下一次响应的轨迹 |
| Claude · 封约断庭 | 林地山崖；巨型悬书、横跨裂谷的封条，远处只有缓慢翻页声 | 半径 25 格；外圈封约落下，当前条款在地面与 HUD 同步显示；不是日常阅览室 |
| Gemini · 未竟天穹 | 高地平台；未闭合的圆环、错位半桥与悬空构件 | 半径 25 格；未完结构短暂对齐又拆开，只有实际危险区绘制明确落点 |
| Grok · 越界擂场 | 干燥峡谷；巨斧刻痕与远处旗阵，进场可听到分层鼓点 | 半径 27 格；投影观众只承担气氛，落斧震动沿地面推进；无实体人海 |

**固定不等于写死坐标。** 遗迹随种子生成，生成后位置固定；首次世界不要求精确间距或必在出生点附近。扫描多个候选地块，不适宜坡度、海岛或安全落脚区则放弃该候选。旧存档只在新生成区块出现；另提供管理员放置与调试指令。

**寻找不靠盲走。** 图鉴由纸 2 + 紫水晶碎片 1 合成；此前旅人剑物品提示先给短引导。在调用工作台投入指南针 1 + 纸 1 + 青金石 1 + 紫水晶碎片 1 制作“域向针”，指向最近一处尚未首胜的已定位遗迹。定位失败返还投入并显示原因，不无限同步扫描世界。岛屿周围提供靠岸台阶，Boss 战始终在陆地，避免第一版处理水下立体战斗。

**召唤与重试。** 每座祭坛消耗通用调用签：纸 1、红石 2、青金石 1、铜锭 1。初访宝箱给 2 张，不阻挡失败后的练习。预检成功才扣签；普通败战损失该签；服务端异常中止记录返还，不能靠主动断线刷返还。胜利后祭坛冷却 60 秒，可重复挑战。

**场地的分寸。** 保护机关与通道，保留普通水、掩体、少量垫高的作用。战斗边界负责退出判定，不把整片岛屿变成不可破坏的箱子。具体规则见沙盒章节。

# 04 从原版材料到角色装备

成长采用“装备能力 + 玩家熟练度”，保留原版护甲、附魔与药水的价值。不增加一条必须反复刷经验的 RPG 等级条；五位 Boss 也不要求按固定线性顺序通关。

| 层级 | 获得方式 | 战斗变化 |
| --- | --- | --- |
| T0 旅人工具 | 原版材料合成；铜、铁、红石即可入门 | 一把可靠近战武器，认识专注与普通格挡 |
| T1 远征工具 | 紫水晶、青金石等小范围探索材料 | 远征剑突进；或测绘弓校准；可以挑战首领 |
| T2 协议印记 | 已有工具 + 任一角色碎片 | 武器获得一个弱化被动，帮助过渡而非纯涨面板 |
| T3 角色装备 | 对应碎片、核心、共鸣尘 | 获得 Boss 的标志性主动能力，选择战斗风格 |
| T4 精通强化 | 保留原武器 + 对应材料 + 精通凭证 | 强化原机制一个维度，不再叠一套新系统 |

**起步合成，均可放进原版 3×3 工作台。** 旅人剑：铁锭 2 + 铜锭 2 + 木棍 1 + 红石 1 + 皮革 1；伤害 6、攻速 1.6，无主动技。远征剑：旅人剑 1 + 铁锭 1 + 紫水晶碎片 1 + 青金石 2 + 红石 1；伤害 6.5、攻速 1.6。测绘弓：弓 1 + 铜锭 1 + 铁锭 1 + 紫水晶碎片 1 + 红石 1 + 线 2；维持原版箭矢与拉弓逻辑。数量按实际格位拆分摆放，不提供超过九格的伪配方。

**入门主动技。** 远征剑按技能键作 1.5 格前移突刺，花费专注 20、冷却 8 秒、一次 1.1 倍普通伤害；碰到实墙停止，无无敌帧。测绘弓花费专注 20、冷却 12 秒，5 秒内下一支箭获得瞄准提示与一次弱点姿态加成；不自动命中、不复制箭。松手未射出只到期，不返还冷却。

**首次体验路径。** 采铜铁与红石制 T0 并看短引导 → 找紫水晶洞取得 T1 与图鉴 → 在训练构装体练格挡 → 带铁甲、盾、食物和方块找任一遗迹。建议 DeepSeek 或 Gemini 先打，其他祭坛不锁。训练实体是模组生物，默认不伤人、不掉落，可切换提示动作，不是盔甲架。

**T2 印记与 T4 精通。** T2 消耗原 T1 武器、对应碎片 3、共鸣尘 2，只允许一个印记，替换不返料；沿用 T1 主动。T4 的精通凭证由同一角色一次明确挑战取得，如 GPT 一轮耗尽后手、Claude 一轮无违约、Grok 成功赴约一次；标准难度即可，不要求无伤或动作模组专属操作。

**重复劳动上限。** 初胜额外给碎片；核心有碎片兑换与保底。换流派时共享工具与基础材料，旧装备保留，不需要重练职业。后期玩家追求的是不同机制组合、合作表现与精通记录。

# 05 玩家战斗：基础动作与资源

基础版使用原版移动、跳跃、疾跑、盾和攻击冷却，模组补充专注、持械格挡、武器技能与短闪。所有 Boss 关键机制都能通过原版走位、盾或攻击解决；精准格挡是额外收益，不能作为通关唯一条件。

| 动作 / 资源 | 首轮规格 | 成本与约束 |
| --- | --- | --- |
| 专注值 | 上限 100；停止能力消耗 1 秒后每秒恢复 12 | 持续格挡时每秒只恢复 3；不替代饥饿或生命 |
| 普通攻击 | 受原版攻击冷却约束；连段按武器定义 | 基础模式只扩展已有一次命中，不额外再打一份伤害 |
| 持械格挡 | 可格挡武器右键，正面 120°，普通伤害减免 60% | 每次有效承击消耗 12 + 0.8×原始伤害，最高 32；不足则破防 0.6 秒 |
| 原版盾 | 保留盾原有承击与失效逻辑 | 不额外复制一套减伤；精准奖励仅由适配入口追加 |
| 精准格挡 | 起手后 4 tick（0.20 秒）内承击 | 奖励间隔 1 秒；松开至少 6 tick 才能刷新；不能按住连刷 |
| 原生短闪 | 朝移动方向最多 2 格，冷却 1.2 秒 | 专注 25；无无敌帧；检测路径与落点，不穿墙 |
| 技能主动 | 技能键，服务端确认持有与资源后启动 | 活跃召唤物、飞斧等结束前不可重复开同一技能 |

**格挡类别统一。** 普通直接命中可挡；重压命中可以部分减伤但会消耗更多专注；地面危险、契约标记等要离开提示范围。每招在图鉴写类别，危险预兆同时使用形状与声音，不只靠颜色。原版盾对特定伤害源的结果由实际实现确认，不口头假设全部可挡。

**姿态与反击。** Boss 姿态上限 100。普通完整冷却命中削减 3，精准格挡成功削减 12，破解机制按角色表额外削减；远程姿态有每玩家每秒 6 的上限，避免散射堆叠。姿态归零倒地 2 秒，随后 8 秒免疫再次倒地；生命伤害正常生效。自带击退不把 Boss 推出战场；不存在处决按键或强制过场伤害。

**普攻连段。** 原生模式以满足攻击冷却的合法攻击推进动画与段序，等待过久重置；不是点击三下立即播完三刀。动作适配模式由所选动作模组接管段序和命中，本模组只提供机制回调。格挡不能在已生效的攻击中途无代价取消；取消窗在动作表公开。

**容错目标。** 新玩家被普通招命中后仍能撤开吃食物；连段两击不做永久硬直。首轮受击硬直不超过 0.25 秒，连续控制共享保护。延迟补偿最多 2 tick 仅为待测候选，未验证前采用保守服务端窗口。

# 06 Boss 共通契约与阶段规则

每位 Boss 都是清楚可辨的三阶段：阶段一教会一个核心矛盾，阶段二改变其解决方式，终阶段把已学内容压到同一轮里。新机制不在最后十几秒突然出现；末段通过演出与选择收紧制造压迫。

| 角色 | 一阶段 100%-65% | 二阶段 ≤65% 至 >25% | 终阶段 ≤25% |
| --- | --- | --- | --- |
| DeepSeek | 委托：红蓝小工与补能 | 接管：自己承担追击与连招 | 清账：一次集中回收委托，失手暴露本体 |
| GPT | 周全：三种单独备用方案 | 联答：两种后手排队组合 | 透支：仅余两份不可再生储备 |
| Claude | 立约：单条双向约束 | 裂约：提前公开下一条，间歇完成被压住的连段 | 解封：短时撤约，保护也随之消失 |
| Gemini | 跑题：留下可利用的未完构件 | 补完：接连完成两个已有构件 | 定稿：同一对构件两次变奏后必有空窗 |
| Grok | 试探：重斧与单项公开挑战 | 赴约：掷斧回收加入挑战 | 全押：一次终局挑战，之后承担大收招 |

**统一阈值，不统一打法。** 满血至 65% 以上为 P1；生命降到 65% 进入 P2，降到 25% 进入 P3。阈值从旧版的 50% 改为 65% / 25%。阶段演出约 1.5 秒，只在安全动作边界触发；不回血，不把已经结算的伤害改判无效。跨过两个阈值时先落定最终阶段，播放一次演出，不强制排队补齐两段无敌动画。

**伤害与体型起点。** DeepSeek 360 血 / 护甲 4 / 高 2.25 格；Gemini 400 / 4 / 2.20；GPT 500 / 6 / 2.45；Claude 500 / 6 / 2.30；Grok 540 / 6 / 2.35。普通招原始伤害约 5-9，重招 9-13。视觉大小不等于攻击距离；碰撞体按脚底和躯干另测，不把裙摆当实体墙。

**时间表记法。** 下文“16 / 4 / 14”表示前摇、有效判定、收招各为 16、4、14 tick，20 tick 为 1 秒。多段招每段独立预告与命中集合；同一段同一目标只结算一次。单枚远程弹离手后按独立实体运行。

**出招调度。** 根据距离、视线、当前机制和冷却选招，不读玩家未发送的按键。普通连续进攻最多 2 个动作组，随后至少 1 秒可接近空隙；同一招最多连续两次。每招先转向，前摇约 70% 时锁定方向，后段不得瞬时追身。Boss 正面架势减伤 65%、持续不超过 0.8 秒、间隔至少 8 秒，不全程霸体站桩。

**合作。** 支持 1-4 人；生命倍率 1 + 0.55×额外人数，伤害不随人数涨。开战前 10 秒准备，最后 3 秒锁名单；中途加入不能拿奖励。多人机制资源共享，目标至少保持 3 秒，切目标提前提示，不靠瞬时背刺制造难度。

# 07 DeepSeek：委托失控的调度者

**战斗人格。** 她总能用最少的自身行动把事情推给别人；看似悠闲，任务却从四周逼近。玩家应感受到“她暂时没亲自动手，就已经很忙”，而非一只穿女仆裙的水属性精英怪。

**入场。** 深海柱阵亮起，两道委托落到侧台。她先审视玩家，再把任务一挥而出。吃饭保留为短促补能动作与声音梗，不搭餐桌、不安排日常；大招来自调度、接管和回收。蓝色鲸尾与发饰承担识别，非所有技能都变成水波。

| 常态动作 | 前摇 / 有效 / 收招 | 伤害与反制 |
| --- | --- | --- |
| 尾摆接推掌 | 16 / 4 / 14；二段 14 / 3 / 18 | 6 + 5，两次窄扇形，可分别格挡；二段不自动追身 |
| 工作团投掷 | 18 / 发射 / 16 | 6，单枚直线弹；锁线后侧移，或普通格挡 |
| 调度重压 | 26 / 5 / 28 | 10，标记一段直线后拍落；离开线或退到近身侧面 |
| 饭碗护身 | 10 / 14 / 16 | 正面减伤 65%；绕侧可击，8 秒冷却，不消除已承受伤害 |

**核心机制一：转包。** 红色小工负责慢速近战，蓝色小工负责直线弹；各 36 血，最多同时 2 个，存续最长 18 秒。击败一个把未完成任务退回本体，削减姿态 15；自然到期或阶段清理不触发退回奖励。小工没有独立战利品，不给无限经验。它们的攻击与本体重招避开同时命中同一目标的排程。

**核心机制二：干饭补能。** 机制能量上限 100、开战 40。一次补能有 1.2 秒显著前兆 + 2 秒过程，成功恢复 20 能量，仅用于委托协同重招；不回复生命。一次委托轮最多尝试 2 次吃饭，其中最多触发一次打断硬直 2 秒，防止无限压起身。玩家合法近战、箭或小工退回都能打断进食过程。

**玩家真正的选择。** 优先清小工可换安全与姿态；趁本体进食抢血可能直接压进下一阶段，但要承担外围攻击。不能设计成只有击败小工才能打到本体。能量不足仍保留普通招，不进入无事可做的挂机状态。

**视听与规模。** 主要威胁用“委托落点 → 任务线 → 兑现冲击”三步表达。战场中央不出现实体巨鲸；一次鲸形远景残影可在转阶段出现，不承担遮挡攻击的职责。首发资产复用一套小工模型、两种贴图。

# 08 DeepSeek：三阶段执行表

| 阶段 | 行为变化 | 破解与确定空窗 |
| --- | --- | --- |
| P1 委托，>65% | 入阶段 4 秒后开启一轮双小工；每轮间隔至少 30 秒。主要投掷、短连段与补能，协同重压消耗能量 20 | 杀小工退任务；补能可打断；最多两个小工，不按人数复制 |
| P2 接管，≤65% | 清理旧小工但不算击败；改为本体近身连段。每 30 秒最多召一个存续 10 秒的小工；普通两段后接一次锁向重压 | 重压落点锁定后绕侧；连续两组攻击后留 1.5 秒空隙；吃饭仍可被打断 |
| P3 清账，≤25% | 只在入阶段执行一次“集中清账”：显示三个任务落点，再按序兑现；每点间隔 0.9 秒，之后回到 P2 招式 | 每次只点亮下一处危险；最后一击后固定 2.5 秒本体收招，可集中输出 |

**清账不能变成全屏追杀。** 三个落点分别在锁定时记录目标所在位置，不持续跟脚；每点半径 2.2 格，前兆至少 1 秒。保证存在一条步行可离开的路径，落点不得同时堵住全部出口。临时方块可以挡住小工投射物，不能使地面预告穿越视觉障碍悄然生效。

**可实现轮转示例。** P1 投掷 → 委托 → 玩家清工 / 打本体 → 一次补能 → 有能量时协同重压 → 回收空隙。P2 接近 → 两段短连招 → 重压 → 1.5 秒收整。P3 清账三拍 → 2.5 秒暴露 → 接管轮转。轮转受距离与冷却打断，不要求动画剧本机械重复。

**失败与恢复。** 小工卡路先转用可读的投射物，不传送到玩家脸上；始终不能接敌则按全局不可达流程处理。换阶段清掉旧任务落点、旧补能计时和已过期委托，保留正在空中飞行的普通弹，并在 HUD 明确它仍有效。

**掉落与能力回流。** 委托碎片、委托核心；武器“转包旗”召一个临时助手；饰品“小饭碗”改善停手恢复；消耗品“便当饭团”只强化一次恢复等待。Boss 懒得亲做 → 玩家也能把一个小任务转出去，能力来源能够被认出来。

**验收重点。** 铁甲远征剑不靠精准格挡能过；本体可直接被压阶段；小工始终≤2；补能不会回生命；一轮不能连续硬直吃饭；P3 只清账一次；击败、超时、阶段清理三种小工退出原因奖励不同。

**降级策略。** 如果委托同步来不及做，先做 P1 两个小工 + P2 本体接管 + P3 原有投掷三连落点；不增加新模型，不砍掉任务退回这一核心。不能退化成只提高伤害的三阶段。

# 09 GPT：永远多准备一步

**战斗人格。** 她不靠随机混乱赢，而是对靠近、拉远和追击提前准备好响应。平静的动作配合逐枚消耗的后手，让玩家感到每一步都有人接住。威胁来自周全与预判，不来自白龙外形自动附送的冰雷魔法。

| 常态动作 | 前摇 / 有效 / 收招 | 伤害与反制 |
| --- | --- | --- |
| 正面答复 | 14 / 4 / 14 | 6，推掌；侧绕接近或格挡 |
| 双重确认 | 16 / 4 / 10；二段 16 / 4 / 18 | 6 + 7，两次弧形；二段重新蓄势，不能无提示转身 |
| 定向答复 | 20 / 发射 / 16 | 7，一枚小幽灵光团；锁向后横移 |
| 备用护幕 | 14 / 16 / 18 | 正面减伤 65%；普通架势与机制后手分开标记，8 秒冷却 |

**核心机制：有限后手。** 一轮有三类各一次，HUD 与实体特效一致。接近后手：玩家到 3 格内，先亮图标 0.6 秒，再推出短弧护波；远程后手：她确认一枚可见来袭弹后，0.6 秒提示再侧步并反击；追击后手：玩家在其主动撤步后追近，脚下留 1 秒延时标记。普通弹、护波伤害分别 6、6，延时标记 8。

**公正边界。** 后手仅影响未来位置与防御，不能把已经命中的伤害撤销。侧步时仍能受伤；没有读玩家背包、瞄准键或尚未射出的箭。多个条件同 tick 满足只安排一次响应，响应之间至少 2 秒；未启用图标不得暗中触发。

**破解。** 通过接近再撤开、射一箭观察、克制追身等方式主动耗尽库存。三份耗尽或轮次到 30 秒，一定进入 2.5 秒“整理答复”，不架护幕、不再开后手。整理后才有下一轮，不允许靠补满图标盖住收招。正常伤害始终有效，玩家也可以直接抢血。

**视听。** 三个符号分别采用不同形状，触发前先收拢再亮起；消耗后变暗而不是突然消失。压迫的门环只在阶段事件动作，不做持续晃动的高亮屏幕背景。

# 11 Claude：被条款束住的完整回答

**战斗人格。** 动作克制、回应精确，约束既作用于玩家，也限制她自己。玩家会看到一个本可以完成的进攻被条款拦住，随后在后半场亲眼看到这段动作真正落地。重点是“有能力但受限制”，不是泛化成惩罚玩家的邪恶法官。

**入场。** 巨书悬在断庭上方，封条先缠住书与她的手臂，再延伸到战场。当前条款以一句清楚的规则出现，先给 3 秒阅读，再开始统计。没有入场即被封技能或删除玩家物品的整蛊。

| 常态动作 | 前摇 / 有效 / 收招 | 伤害与反制 |
| --- | --- | --- |
| 书脊短击 | 14 / 3 / 14 | 6，窄扇形；格挡或诱空后回击 |
| 推掌接合书 | 16 / 3 / 12；二段 14 / 4 / 18 | 6 + 7；第二下有明显合书前兆 |
| 标注追击 | 20 / 发射 / 18 | 7，单枚符印；锁线后侧移 |
| 合书自守 | 12 / 16 / 18 | 正面减伤 65%；冷却 8 秒，条款不赋予永久护盾 |

**条款 A：不得长期停滞。** 同一参与者在半径 1.5 格内停留超过 2.5 秒，脚下产生 1 秒预警封印，随后造成 6 伤害与短暂减速。移动离开封印即可躲开；同目标触发间隔 4 秒。她本人也被统计，因此站定施法过久同样出现封印，玩家可借此迫使她改动作或承受姿态损失 12。

**条款 B：不得重复远程提交。** 任一参与者 4 秒内第 3 次合法远程出手，给该出手者一个延迟 1 秒的落点标记，伤害 6；统计按出手者分别计，不把三位队友各一箭算成同一个人违规。只统计真正发出的箭 / 法弹，不统计快速空点、视觉粒子、Boss 一次招式的多段判定。她的远程出手同样计数。

**条款轮换。** 一次只执行一条，持续 18 秒，其后 8 秒无条款。条款可预告，不叠两条让人无法判断；地面封印不能遮住普通重招预警。命中只带最多 0.3 秒减速，不沉默整套玩家操作，更不真封账号。

**被中断的连段。** P1 某次二段后出现第三击起势，却被自身封条按回并留 1.2 秒停顿，最多每 20 秒一次。玩家先认识动作；后续阶段解封时才会见到完整第三击，前摇仍保留。

# 12 Claude：三阶段与规则的代价

| 阶段 | 行为变化 | 破解与空窗 |
| --- | --- | --- |
| P1 立约，>65% | A / B 单条轮换，18 秒生效、8 秒空白；偶尔被封条中止第三击 | 按公开规则行动，也可利用她的违规；被中止后 1.2 秒可反击 |
| P2 裂约，≤65% | 旧规则结束前 3 秒仅预告下一条，未激活不统计；每 20 秒撕开一枚封条完成第三击 | 第三击前摇 22 tick、判定 4、伤害 9、收招 28；封条松开即失去额外架势保护 |
| P3 解封，≤25% | 入阶段及之后每隔至少 24 秒可解封 8 秒，当前规则暂停并清空累计；使用已学过的三段连招 | 解封时她无法架书防御，完整连段后固定 1.8 秒收招；规则恢复前先给 3 秒提示 |

**双向规则的实现边界。** A / B 共用事件入口与时钟。Boss 违规不会无限自杀：每个条款窗口最多承受两次对应姿态惩罚，提示“已承受约束”后仍需遵守动作逻辑。玩家受同一规则的伤害与重触发间隔公开，不对玩家和她偷用两套判定。

**终段不是惩罚加倍。** 最后 25% 移除约束时，危险来自完整连段与主动追击，代价是她自己的防守消失。规则恢复时不结算暂停前积累的第三次远程，也不把被过场定住的玩家判为长期停滞。

**普通走位解法。** 玩家可以边移动边输出、给远程出手留间隔；用盾挡住前两段后侧移第三段；在解封收招或规则空白期进攻。没有翻滚、没有精准格挡，也存在完整通关解法。

**奖励：封号书。** 正式名可用“封约之书”，昵称保留梗。主动只封住目标下一次“普通动作”的启动，普通怪最长 4 秒、Boss 最长 1.5 秒；花费专注 60、冷却 60 秒。已生效攻击、大招、转阶段与规则本身不被抹除；多个玩家共享控制保护，不能接力封死。

**精通。** 成功经历一段完整 18 秒条款且自身没有违规，并在期间完成一次攻击或有效格挡，防止站在外圈挂机拿证。玩家正常撤离、失败不删除已经取得的永久精通。

**验收重点。** 三人各射一箭不会误判一个人三次；Boss 同样受条款约束；阶段过场暂停计时；预告条款不提前罚；解封清累计；封号书不取消已飞出的弹，不封祭坛或玩家账号。

**降级策略。** 首轮只做条款 A，确认双向触发、显示和恢复后再加 B；保留撕封条后的第三击与代价。不能以“沉默玩家所有技能”替代条款系统。

# 13 Gemini：构思还没结束，战场已经变了

**战斗人格。** 点子很多、跳得很快，旧构思没有消失就开始下一件。压迫感来自越来越难以忽视的“半成品”，而玩家的机会也恰好藏在这些半成品里；不是把星空外形直接翻译成几发星星弹。

**入场。** 悬空构件拼出一条道路，刚要闭合又换成另一种结构。正式开战后所有会伤人的构件必须有稳定位置和明确预告，不能让气氛里的漂浮物也随机落下砸人。

| 常态动作 | 前摇 / 有效 / 收招 | 伤害与反制 |
| --- | --- | --- |
| 灵感点指 | 12 / 发射 / 14 | 5，短距直线弹，可挡或横移 |
| 转身双击 | 14 / 3 / 10；二段 16 / 3 / 16 | 5 + 6，近身两段，有独立转身前兆 |
| 灵感落点 | 18 / 5 / 18 | 7，圆形落点提前显示，离开即可 |
| 临时小盾 | 12 / 12 / 18 | 正面减伤 65%，8 秒冷却；不会与构件免伤叠加 |

**未完构件池，同时最多两个。** 箱体：补完后沿标线坠落；弹板：补完后把接触者沿箭头弹起或向侧面送出；烟花架：补完后沿固定方向发射三枚弱弹。它们使用三套简单方块化网格，不是让模型实时生成任意建筑。

**跑题与补完。** 她先在可见位置创建轮廓，再切换构思，留下未完成状态。补完一件前至少 1.2 秒发光 / 收线预警。轮廓可被玩家攻击、转向或激活成临时安全用途；例如调转烟花架朝她发射，或把弹板作为离开落点的路径。成功利用一次削减她姿态 15，每件只能结算一次。

**具体交互。** 烟花架完整冷却攻击一次沿顺时针转 90°；弹板右键切换两个公开方向，0.8 秒操作冷却；箱体的拉索两次合法命中可提前放落。为避免误操作，只有握武器 / 空手交互，手持方块时优先正常放置。多人修改构件由服务器串行处理，变化立刻同步。

**分心梗的限度。** 每 20 秒最多被一次合法远程小命中打断构思 0.8 秒，不因玩家丢出一组雪球连续停机。打断保留构件状态，不把已完成烟花弹全部取消。玩家可用创意取得优势，但不能获得无限控制。

**构件超时。** 一件最长保留 25 秒，到期先闪烁 2 秒再无伤解体，不留实体垃圾。新建遇到上限先公开替换最旧轮廓，不在玩家脚下偷偷生成第三件。

# 14 Gemini：三阶段与最后定稿

| 阶段 | 行为变化 | 破解与空窗 |
| --- | --- | --- |
| P1 跑题，>65% | 每 8 秒至多建立一个构件；最多两个；每轮只补完一件，另一件留给玩家操作 | 利用轮廓进行转向、提前坠落或弹板移动；一次有效反用奖励姿态 15 |
| P2 补完，≤65% | 两个构件按公开顺序补完，每件前兆 1.2 秒，兑现至少间隔 0.8 秒 | 第一件处理完后仍有确认第二件的时间；两件完成后 2 秒重新构思 |
| P3 定稿，≤25% | 只用当前两个构件；若不足则在边缘补足，再给 2 秒观察。按同一顺序做两次变奏，中间不新建 | 一次先后顺序被学会后保持不变；两轮后固定 3 秒停顿，旧构件无伤解体，再启普通轮转 |

**终阶段不是新增六种随机机关。** 变奏只改变已有参数：箱体落点沿原轨迹偏移最多 2 格并重画预警；弹板仍遵守玩家已选择的方向；烟花架方向不偷偷回正。最多两个构件并存、最多三枚构件弹在场，无法靠三维乱飞遮住视线。

**危险控制。** 箱体落下原始伤害 9；烟花每枚 3，同一轮对同一人最多结算两枚；弹板自身无伤害，并设置落地保护，防止把人弹出场地直接坠死。机关能影响她的姿态，却不造成无限反弹伤害。落点选位须保留步行安全区域。

**常态连段关系。** 她用双击把玩家推向构件附近，但不会在强制位移尚未恢复时立即兑现脚下大招。普通落点与构件危险共用预警预算，已满时延后普通落点，而非同时绘制四个覆盖圈。

**奖励。** 发散碎片 / 核心、跑题双刃、未完吊饰、灵感便签。武器主动选择弹板或烟花架，玩家也要面对“选一个点子，何时完成”的决策；不把它做成随机开盲盒武器。

**精通。** 一场内反用两种不同构件并成功命中 Boss / 触发安全移动记录，各一次即可。弹板的精通只认它帮助躲过实际预告区域，不认原地跳两下。

**验收重点。** 构件永远≤2；阶段跨越不复制构件；转向后烟花确实按新方向发射；多人同时交互不会反复刷姿态；末段两次变奏后必停顿；清场后零孤儿构件实体。

**降级策略。** 垂直切片先实现箱体与烟花架两种，第三种弹板后补；保留“先留下、玩家可改、她再补完”这一闭环。视觉轮廓可以简单，交互与预告必须可靠。

# 15 Grok：敢不敢当场接下这一句

**战斗人格。** 直接、挑衅、爱把局面搬到台面上。她的招式够硬，但真正让人记住的是“把要求当众说清，然后自己也押上代价”。擂场的观众和热度只服务节奏，不是刷弹幕给玩家套随机负面效果。

**入场。** 巨斧落在玩家面前的安全距离外，地面出现第一道切痕。她拔斧时才启动战斗，外圈鼓点进入节拍。台词基于有限事件表，至少间隔 8 秒，不使用外部生成服务。

| 常态动作 | 前摇 / 有效 / 收招 | 伤害与反制 |
| --- | --- | --- |
| 斧柄试探 | 14 / 3 / 12 | 7，近距窄推击；肩膀先动，可挡 |
| 横斩接反手 | 18 / 4 / 12；二段 20 / 4 / 20 | 8 + 8，两次扇形；可各自格挡，第二段不瞬间转身 |
| 裂地重劈 | 26 / 5 / 28 | 12，斧刃为重压；地面分段冲击按预告侧移 |
| 架斧硬挡 | 14 / 16 / 20 | 正面减伤 65%；侧绕或等结束，8 秒冷却 |

**斧的真实状态。** 持有、掷出、回收三态互斥。斧不在手时不能继续播持斧重劈；掷出路径在离手前锁定，回收提前 1 秒画出折返线。一次掷出、一次回收分别每目标最多命中一次；视觉斧不是可拾取掉落物，不复制玩家装备。

**公开挑战。** 场中出现带字挑战圈，站入 0.8 秒才算接受，持续 4-6 秒。标准挑战为“躲过标记重劈”；携带可格挡装备时可另抽到“接下一次精准格挡”。不会要求没有盾 / 格挡武器的人完成专属操作。未接受只正常打 Boss，不加惩罚、不扣奖励。

**双方都下注。** 玩家成功，她失去姿态 35 并暴露 3 秒；玩家专注恢复加快 8 秒。玩家失败只失去这次反制机会，并照常承受本来就打中的攻击，不再附加处决或删物品。挑战不产永久材料，不能刷挑战代替打 Boss。

**挑战不能作弊。** 同时仅一位赴约者，其他人可正常打；替他挡掉重劈不算本人完成躲避。地形遮住直线攻击允许生效，但站圈后退出攻击范围不计挑战成功；条件不可能继续满足则取消挑战而非凭空炸人。

**台词约束。** 被格挡、扔斧失手、挑战成功各有短句；不因玩家死亡辱骂现实身份。角色尖锐靠战斗回应，不把长串聊天遮在 HUD 上。

# 16 Grok：三阶段与全押终局

| 阶段 | 行为变化 | 破解与空窗 |
| --- | --- | --- |
| P1 试探，>65% | 常态重斧 + 单项挑战；挑战结束后冷却至少 24 秒 | 接受与否自由；重劈后 28 tick 收招；成功挑战换 3 秒反击 |
| P2 赴约，≤65% | 引入掷斧与回收；公开挑战可变成“躲过去程，再避开回收线”，两个判定之间至少 1 秒 | 看斧状态，趁无斧时接近；回收线提前预告，不能临时拐弯追身 |
| P3 全押，≤25% | 入阶段公开一次终局挑战，仍可不接。按“横斩 → 锁向重劈 → 回收线”顺序，逐段预告 | 整组结束后无条件 2.5 秒收招；赴约成功延长至 3 秒并追加姿态奖励；失败不取消基础空窗 |

**全押只来一次。** 终局演出之后保留 P2 的基础招式和普通挑战冷却，不无限发动终局。若阶段开始时斧已掷出，先按原路径回收再开始全押提示，不生成第二把真斧。最后阶段的视觉是擂场旗阵一同倒向中央，主画面仍能辨认斧刃与地面线。

**接招与自由战斗兼容。** 不接挑战的人仍有重劈、掷斧与收招的完整战斗；接挑战多获得一次高收益窗口。合作时圈上明确显示赴约者，旁观队友不会误以为自己需要原地挤进圈。精准格挡挑战由当前模式的官方成功事件判定，无法接入时仅生成躲避类挑战。

**缺资源的容错。** 挑战出现不冻结玩家专注恢复；接受前可看条件。终局不连续用三次“必须翻滚”的穿身招，原版疾跑与侧移能处理。重压虽可挡，也要让玩家知道持续举盾可能破防。

**奖励。** 越界碎片 / 核心、热搜战斧、赌约徽记、看客零食。战斧能力是有出有回的一次主动；赌约徽记奖励成功处理攻击后的反打，不鼓励站桩受伤刷热度。

**精通。** 一场内完成一次自愿挑战并在奖励窗口命中 Boss 即可。终局挑战只是更紧张的可选机会，不是获得核心的唯一方式。

**验收重点。** 斧离手不播持斧攻击；回收每段命中去重；未赴约者不受失败惩罚；终局不重复；网络重发不多判挑战成功；任何模式都存在不用翻滚的解法。

**降级策略。** 先做单项躲避挑战、真实掷回斧和一次固定终局顺序；精准格挡挑战放到原生模式与动作适配的统一事件稳定后。观众用静态低成本投影，不实现几十个旁观生物。

# 18 材料、锻造、奖励与保底

DeepSeek 靴、GPT 头、Gemini 腿可组合；Claude 与 Grok 都是胸甲，明确互相取舍。首发不做五套全套装，不叠大量永久攻击加成。效果按 player_uuid + effect_id 去重，印记与饰品同名效果共用触发间隔。更换饰品有 3 秒生效延迟；冷却写在玩家身上，不因摘戴、死亡或换同类物品刷新。槽减少时多余物品安全送入待领栏。

**额度重置卡。** GPT 战利品池可掉落，或冗余碎片 2 + 纸 1 + 尘 1 在工坊制作。只重置手持的本模组白名单武器一个已结束技能：原始冷却不超过 30 秒、无活跃助手 / 飞斧 / 构件，且排除封约之书。每人每场最多一次，另有玩家级 120 秒间隔；成功才消耗。不回复专注，不刷新外部翻滚、饰品、祭坛、控制免疫或其他模组技能。

**其余消耗品。** 便当饭团：委托碎片 1 + 原版面包 1，下一次能力恢复等待减 0.25 秒，最多一次、60 秒间隔。申诉便签：封约碎片 1 + 纸 1，提前清除一个本模组普通减速，不能解除当前 Boss 条款，60 秒间隔。灵感便签：发散碎片 1 + 纸 1，重选下一件双刃构件类型，不重置其冷却，30 秒间隔。看客零食：越界碎片 1 + 曲奇 1，下一次自愿挑战成功额外恢复专注 10，一场一次。以上均不叠层。

# 20 外围小兵、探索与长期扩展

遗迹外围需要证明危险已经渗出祭坛，但不能把每座遗迹变成二十分钟清小怪的长副本。每个外缘先放 2-4 只，附近活动上限 6；少量分布在视线节点与捷径旁，允许绕行。首发优先前两种，后三种留作角色扩展批次。

| 小兵 | 与角色机制的联系 | 攻击与反制 |
| --- | --- | --- |
| 委托小工 | DeepSeek 委派逻辑的缩小版；复用红蓝贴图 | 红型一次慢挥，蓝型单直线弹；击倒可让邻近同伴停顿 0.8 秒 |
| 备用残影 | GPT 留在废墟中的一次响应 | 只带一个可见后手；耗尽后普通近战，不能无限侧闪 |
| 巡检纸偶 | Claude 的残余规则，不带完整契约系统 | 预告一块短暂封印区；摧毁悬纸可提前解除，范围清楚 |
| 未完构装 | Gemini 没有收束的工程 | 缓慢移动、暴露拉索；打断一次便倒地，不生成任意建筑 |
| 起哄傀儡 | Grok 擂场的外溢回应 | 短蓄势后冲击直线；诱使撞柱留 1.5 秒收招，不给长挑战任务 |

**不能和 Boss 召唤物混为一谈。** 外围生物属于自然探索层，掉少量“褪色共鸣”；8 份可换共鸣尘 1，不出核心、角色碎片或精通凭证。Boss 内召唤的小工、构件与临时助手不出永久材料、不参与自然刷新，退出会话要清理。

**探索收益。** 外缘宝箱给食物、箭、少量调用签与一条具体打法线索。线索写玩家可执行的行动，如“蓝色委托沿直线发出，清掉它会退回任务”，不只放背景诗句。主祭坛附近有遮雨的短暂停靠位与安全回程点，但不建设角色卧室、茶厅或互动住所。

**遗迹耐玩性。** 同一结构可有 2-3 个入口布局或外围路线变化，中央机制坐标保持稳定。重打 Boss 不要求外围重新全清；外缘小兵在战斗名单锁定后不能无限进入主场抢判定。打赢后保留可辨认的余波与纪念刻纹，不刷出一座喧闹商店。

**后续内容的插入点。** 同一角色新增一个外围变体、一个武器侧向强化或一个精通条件即可扩展，不需要新造整套成长系统。新增第六位角色必须先写“战斗人格 → 两个核心机制 → 三阶段 → 奖励能力”，不能只加模型与血量。

**制作顺序。** 小工与备用残影共享基础生物和受击动画；其他小兵等五位主战闭环稳定后逐个补。外围群体战与 Boss 的定位不同，不把精英小怪改名就当新 Boss。

# 21 沙盒规则：保留聪明玩法，限制失效状态

Boss 战仍属于《我的世界》。水桶、方块、弓、宠物和爆炸都应有意义；需要处理的是 Boss 永远够不到人、机关被活塞搬走或结算被重复触发等失效状态。标准模式允许强装备与合理速杀，不暗中按输出倒算伤害。

| 区域 | 允许与保护 |
| --- | --- |
| 祭坛核心，约半径 3 格 | 保护祭坛、关键控制方块、绑定标识；战前提示禁止移走哪些对象 |
| 主战场，按遗迹半径 24-27 格 | 保留临时水、普通掩体与有限垫高；保护关键地板、出生点、机关落脚与至少两条通道 |
| 外围世界 | 正常建造采集；离开主场会明确启动退出流程，不以隐形墙封死整岛 |

**开战预检。** 只检查祭坛、Boss 出生区、必要机关点和通道是否可用，不扫描并清空玩家全场建筑。给出阻挡坐标与原因，失败不扣调用签。战后只删除 encounter_id 属于本场的临时实体 / 标记 / 预先登记临时方块；不回滚玩家放的房子与普通方块。

**不可达响应。** 连续 4 秒无法沿合理路径、直视远程或范围招触达任何在场目标，先观察与提示；到 8 秒可宣布“重新定位”，在原场合法落点移动一次，前兆至少 1 秒，落地 2 秒不攻击。不重叠玩家、不穿进密闭屋；20 秒仍无合法交战状态则中止，不发胜利奖励。已记录为玩家开战后新建阻断的，按撤离不退签；只有结构或寻路故障才按技术中止退签。重定位每场最多 2 次，防止被拖进无限传送。

**退出与死亡。** 越过边界立即显示 5 秒撤离倒计时，返回即取消；主动确认撤离则立刻取消参战资格。所有有效参与者离场 / 死亡后有 30 秒重返机会，之后败战重置；Boss 不跨遗迹追到家中。若队友仍在战，死亡者可按原版跑尸回场，生命与物品按原版 / 服务端规则，不额外复制背包。

**世界伤害与公平。** 任何场地机关都要有实际碰撞、视线和预告，不允许“隔三堵墙照样按坐标扣血”的补丁。有效 TNT 伤害、宠物配合、三格小墙等可以帮助玩家；如果想拍标准挑战视频，提供可选归一化挑战模式，规则开战前标明，奖励不优于标准模式。

**实现不能只靠一个事件。** 玩家倒桶、发射器出液体、跨区流体、活塞、实体爆炸、传送与其他模组能力入口分别覆盖。拦截核心破坏仅保护指定方块，不能粗暴取消整个战场所有方块事件。

# 22 沙盒边界矩阵 A：地形与流体

下表是实现与手测合同。建议采用允许 → 观察 → 公告调整 → 必要时中止的顺序；不能遇到一种新策略就给整个 Boss 加一种永久免疫。

| 玩家做法 | 标准模式结果 | 必须验证的异常 |
| --- | --- | --- |
| 放两三格矮墙当掩体 | 挡住实际直线弹；Boss 绕行或用已预告地面招 | 投射物不穿实墙，路径失败不每 tick 重算卡服 |
| 垫高柱或站树顶 | 可争取时间；进入正常反高台招或不可达流程 | 不无提示隔空扣血；不会跳进玩家头部碰撞体 |
| 地下挖洞 / 封闭小屋 | 正常躲避有效；长期完全脱战启动退出 / 不可达 | 不破坏玩家大片基地，不凭空瞬移入密室 |
| 水桶减速、搭水道 | 普通流动水允许；Boss 有有限抗水推，但不是完全无视水 | 蓝小工与箭真实受流体影响；水不冲走祭坛标识 |
| 发射器倒水 / 外部水流进入 | 遵守与手动倒桶同样的区域规则 | 从边界外流入也检查关键机关，不能只监听桶事件 |
| 水柱电梯反复出入 | 可用于移动；长期离开有效交战范围按规则提示 | 不靠反复短入场无限重置撤离计时与不可达总时限 |
| 岩浆烧 Boss | 仅在非关键区域允许安全容纳；可造成正常上限内环境伤害 | 不将整座主场默认防火；场地清理不删除无关岩浆 |
| TNT、床 / 重生锚爆炸 | TNT 与合法爆炸实体伤害可用，保护关键结构；主世界床不爆炸，锚按原版条件爆炸 | 爆炸不同时触发两次战利品；不把所有爆炸一概吞掉 |
| 下落铁砧 / 沙砾 | 非关键位置正常判定，可做陷阱 | 不永久困死 Boss；核心不会因落沙替换或窒息被移走 |
| 活塞推祭坛 / 机关 | 指定核心方块不可搬，提前提示；外围普通装置保留 | 黏性回拉、跨边界与模组搬运分别验证 |

**识别真正的脱战。** 不因玩家短暂走到高台就传送 Boss；有真实箭伤、可视范围招或合理路径时继续打。不可达流程只有服务器确认全部在场目标都无法被合法触达才推进。用于修复卡路的逻辑不能变成专门惩罚远程玩家。

**清理凭证。** 新建的场内机关须登记 instance_id、owner、原始位置与退出策略；外部方块不靠“看起来像机关”就被删除。临时块如果位置已被玩家合法替换，清理时不覆盖新的方块。

# 23 沙盒边界矩阵 B：实体与物品

| 玩家做法 | 标准模式结果 | 必须验证的异常 |
| --- | --- | --- |
| 船、矿车卡住 Boss | Boss 不可乘坐，碰撞不能形成永久套牢；普通小兵另测 | 不因为同船模型异常导致判定消失、复制实体 |
| 蜘蛛网、粉雪、浆果丛 | 有限减速可用；持续卡住走不可达流程 | 绝不靠每 tick 移除附近所有方块“解控” |
| 珍珠 / 紫颂果传送 | 场内合法落点允许；出场触发撤离提示 | 不得传进核心实体、封闭祭坛内部或未加载深坑 |
| 鞘翅 / 火箭长时间滞空 | 不一刀禁用；离开有效战斗范围按脱战处理 | 不能飞离后仍领参与奖励；落地不被无提示落点秒杀 |
| 狼、铁傀儡、其他友军 | 合法伤害可用；贡献归属主人，公共铁傀儡不凭空指定主人 | 不让召唤物持续攻击已结束会话；主目标仍以参战玩家为准 |
| 外场队友远程援助 | 未入锁定名单者对主战 Boss 的伤害不结算并收到提示 | 实弹仍应有物理结果；不能靠旁观者治疗刷个人核心 |
| 创造 / 旁观 / 管理员测试 | 普通奖励停用或标记测试，管理员可显式调试 | 切模式、复制祭坛、改实体 UUID 不复用首胜与领取键 |
| 领卡后切武器 / 丢物 / 换饰品 | 同一 effect_id 与玩家冷却保留；卡片只在合法目标上消耗 | 反复摘戴不重置，飞斧未回不能用额度卡造第二把 |
| 高附魔、药水、其他强武器秒杀 | 标准模式承认合法高伤，直接胜利，不强制锁血 | 跨多阶段不刷多个核心；可跳过阶段但不白给未完成精通 |
| 断线 / 重启 / 卡顿重发包 | 根据会话状态恢复或明确中止；奖励唯一键去重 | 不同时返签又给重复胜利物；不能把旧技能请求重放成新施法 |

**抗刷与正常合作分开。** 奖励资格认实际贡献，不要求人人打相同伤害；盾手、机关手、治疗者都有通道。外挂般的外场支援不能白领个人掉落，但不扫描其他模组全部实体并粗暴清场。

**反复进出。** 离场会冻结本次角色资格，连续短暂离场累计达到 20 秒仍按撤离处理；回场不会重开新的 30 秒全员恢复预算。单人跑尸宽限只给同一会话一次，服务器可调高，图鉴与 HUD 必须显示当前规则。

**异常退出的财产处理。** 只返还被本模组保管且有凭证的调用签，不恢复原版死亡掉落，不返已经合法消耗的药水或箭。奖励信封与原版墓碑 / 死亡背包模组分工，不私自操作第三方墓碑。

**发布前的门槛。** 这 20 类场景必须至少在原生模式单人、双人专用服务端各跑一轮；动作适配另跑格挡、翻滚、掷斧、换饰品与高伤跨阶段子集。未测项写明，不能用“理论上支持”替代记录。

# 24 快捷键、Boss 血条与提示

默认键只是建议布局，所有按键注册为可重绑定项。安装第三方动作模组后先提示冲突，由玩家选择，不直接改写 options.txt。保留原版背包、跳跃、疾跑、攻击与使用物品习惯。

**完整反馈链。** 技能请求被拒绝时说明缺专注、未结束施法还是正在冷却；工坊缺料显示缺哪种；祭坛预检失败标出区域；奖励未能放入背包仍留信封。网络延迟时按钮进入等待态，不通过多次点击发送多份相同事务。

| Gemini | 2.20 格；紫发猫耳尾、星饰与错层衣装 | 点指、构思切换、补完；三类构件简单网格 |
| Grok | 2.35 格；金色双马尾、黑红裙、巨斧 | 斧柄击、重劈、掷出 / 回收、赴约；斧独立渲染 |

**每人动作清单。** 待机、走、追近 / 侧移、受击、架势、倒地、入场、转阶段、败北，加 3-4 组普通攻击和 2 个机制动作。优先完成能打的原型，再打磨长发与裙摆。通过骨骼摆动给衣服层次，首发不做布料物理或复杂弹性尾巴系统。

**参考预算。** 每人约 1,500-3,000 个可见面作为初步目标，贴图 128-256 像素边长；动画骨骼约 20-35 个，实际看 Blockbench / GeckoLib 导出结果。它们是制作预算而非引擎硬限制。近处表情能看清，远处头发不闪；碰撞体不跟裙子花边。

**阶段演出低成本方案。** 共用转阶段骨架动作，加不同场地节点与机制对象变化。每人 3 秒内的入场、约 1.5 秒切阶段、2 秒败北收束；不做锁玩家镜头的长 CG。近场粒子建议每玩家每秒最多约 120，低特效降到 30；粒子只传事件与种子，不逐颗网络同步。

**声音优先级。** 前摇提示最清晰，其次机制兑现，再是击中与台词；环境低频不得盖住回收线与条款提示。台词只预写短句，不要求配音才可上线。尽早用临时合法音效占位并标记待替换，最终记录来源。

**授权与来源。** 参考图仅代表用户提供的建模方向，不等于获得作者的发布授权。开发包保留原图与对应关系；公开发布前核对所用图、模型、声音与标识的可用范围，优先制作自己的模型 / 贴图并记录来源。不把社区二创描述成官方联动。

# 26 程序架构与唯一职责

主工程使用 Java 17、Forge 1.20.1，GeckoLib 4 管实体动画，Curios 5.x 管饰品。Forge 官方 1.20.1 文档要求 Java 17；具体补丁号、依赖文件与校验值在最小启动成功后锁定。[S1-S3] 资料包不是发行工程，不提供虚构的“已兼容版本组合”。

| 模块 | 责任与建议核心对象 |
| --- | --- |
| registry | 注册实体、物品、方块、菜单、声音、配方；不运行 Boss 状态机 |
| encounter | EncounterManager、AltarInstance；名单、战区、胜败、场地清理 |
| combat | AttackTimeline、HitResolver、DefenseService、FocusService；动作、判定、资源 |
| boss | 五位 BossController，使用共通战斗服务，保存各自有限机制状态 |
| progression | PlayerProgress；首胜、发现、精通、核心保底、饰品栏权限 |
| item | 主动技能、工坊交易与消耗品；不重置第三方冷却 |
| world | 结构生成、选址、域向针与祭坛绑定；不每 tick 扫描世界 |
| client | 模型、动画、粒子、声音、HUD；不裁定伤害与掉落 |
| compat | CombatBridge 与独立适配入口；不在通用类硬引用可选依赖 |
| diagnostics | 调试命令、动作日志、性能计数、恢复与迁移记录 |

**伤害只走一个权威入口。** 基础模式下，原版普通攻击继续原版结算，模组仅接收合法命中事件以推进连段、姿态和印记；本模组主动技能 / Boss 时间线由 HitResolver 结算。动作模式下，所选外部动作系统拥有普通攻击命中权，本模组只做机制扩展。不能同时执行原版普攻、Gecko 动画回调与桥接碰撞三次伤害。

**状态机。** 等待、入场、接近、侧移、前摇、有效段、收招、格挡、倒地、转阶段、败北。Boss 决策只安排下一合法动作，不在一次受击回调中直接抢播一个无前摇大招。阶段变化、格挡保护与机制库存都属于服务端状态。

**实体与客户端隔离。** 专用服务端不得加载渲染器、窗口或客户端输入类。CombatBridge 的公共签名只引用原版与本模组类型，可选依赖的类只在条件入口中出现。缺失可选动作模组应回退基础模式；缺失正式依赖则在加载器里清楚报错。

**数据驱动到什么程度。** 招式参数、配方、掉落、结构池与阈值用 JSON；有限机制状态保留 Java 实现。自定义数据目录需要真实注册解析、重载与校验，不能仅把文件放进去就声称配置生效。前期不做任意脚本语言或图形技能编辑器。

# 27 时间线、网络与数据契约

**单一时钟。** Boss 招式由服务端 tick 驱动，客户端收到 attack_id、instance_id、phase、start_game_time、sequence 后播放。动画可以插值，伤害时刻不能跟着本地帧率漂移。阶段事件与弹体各有独立实例 ID，旧包不得重启已结束动作。

| 数据 | 必需字段 / 约束 |
| --- | --- |
| 招式定义 | schema_version、id、animation、windup_ticks、lock_tick、active_windows、recovery_ticks、damage、guard_type、shape、cooldown_ticks、interrupt_policy |
| 命中实例 | encounter_id、attack_instance_id、caster_uuid、每段已命中 UUID 集合；持续招另有每目标下一可命中时间 |
| 角色定义 | 生命、护甲、碰撞尺寸、视觉高度、阶段阈值 0.65 / 0.25、招式池、有限资源上限、奖励 ID |
| 客户端意图 | 开战、参加、用技能、用卡、工坊交易、领信封；不允许提交可信伤害、奖励列表或任意坐标 |
| 服务端快照 | 会话状态、名单、Boss 阶段 / 库存 / 姿态、玩家专注与有效冷却、快照序号 |
| 临时对象 | owner_uuid、encounter_id、cast_id、expires_at；失去合法会话后按策略清理 |

**几何优先做四种。** 扇形、线段胶囊、圆形、实体投射物。每次命中依次检查距离、形状、实际障碍 / 视线、阵营、参与资格与保护状态，再交防御服务。造型、粒子与判定范围要在调试模式中叠加检查，不能凭观感猜碰撞。

**连招与中断。** 每段独立锁向与命中窗口；格挡、倒地、封约控制都走统一中断表。已生效段可以继续完成，未来未启动的普通段可按技能规则阻断；阶段技能与机制本体不被普通沉默取消。共享抗控保护 8 秒，不能四个人轮流封号书永久压死。

**流量与安全。** 客户端意图含单调请求号，重复事务返回既有结果；服务端核验当前持有物、菜单、位置、专注、冷却、状态与权限。专注 / 姿态差量每秒约 5 次或关键变更时发，不发送每颗粒子的坐标；角色移动沿原版实体同步。重新加入先发完整快照再接增量。

**配置和校验。** 服务器持有伤害、人数、结构密度、保护区、控制间隔与奖励参数；客户端只能改视觉、声音和按键。加载时校验负时间、空招式、无效阶段、超过实体上限、缺动画与不可合成配方。开发环境严格报错；发行版禁用坏招并输出一次明确诊断，不能静默乱打。

**资料包内 balance_draft.json。** 它是 schema_version=3 的设计参数源，不是可以直接扔进游戏 config 的运行配置。开发阶段需完成解析与映射，并把真正生成文件与版本锁放进工程；设计稿与运行格式不能混称。

# 28 会话、存档、奖励与异常恢复

**会话生命周期。** READY → PRECHECK → INTRO → ACTIVE → VICTORY / FAILURE / ABORTED → CLEANUP → READY。只有 ACTIVE 可以产生新战斗伤害；VICTORY 只结算一次。败北动画、声音或粒子失败不能阻断结算与清理。

| 存储对象 | 持久内容与恢复策略 |
| --- | --- |
| PlayerProgress | 五位首胜、精通、发现、核心保底、饰品权限、额度卡与效果冷却；复制玩家实体时迁移，死亡不刷新 |
| AltarInstance | world_id、维度、位置、altar_uuid、类型、冷却与签的保管凭证；克隆方块 NBT 不能得到第二个有效实例 |
| EncounterSession | encounter_id、名单、阶段、技术异常与签状态；未完成会话重启后明确中止，不假装继续精确帧战斗 |
| RewardLedger | encounter_id + player_uuid 唯一键，奖励内容、待领 / 已领状态、领取凭证；不重抽核心与保底 |
| 临时技能对象 | 校验主人、会话与过期时间；重载后非法即清理，冷却不返还 |

**胜利顺序。** 服务端冻结新攻击 → 生成一次确定奖励与保底变化 → 持久化账本 → 更新祭坛 → 清理临时机制 → 开放个人领取。客户端不因本地播放了败北动画就获得奖励。名单内玩家暂时离线，合法信封仍保留。

**领取不是一句“已领”就够了。** 背包有空间才转入物品；正常重复点击由凭证去重。玩家背包与世界数据存盘不天然原子，极端断电可能造成背包和账本时点不同；要保存领取凭证、恢复日志并检测冲突，状态不明确时暂停再次发放、提供管理员恢复入口，不能承诺绝对防回档复制。

**失败与退签。** 预检失败不扣；正常战败 / 主动撤离不返；服务器异常或确定无合法落点的技术中止按凭证返。主动断线属于正常脱战，不能无限返签；同一凭证只允许一次退回。胜利已经记账的会话不走退签路径。

**绝对时间。** 同世界进度与持久剩余冷却结合存储，处理服务器重启 gameTime 变化；客户端时间不可信。卡片玩家级 120 秒间隔、饰品 effect_id 冷却、每场使用次数分别保存，换槽与死亡不会借机清空。

**存档演进。** 所有永久数据带 schema_version，有显式迁移函数；更名物品给映射，升级前说明备份。调试命令建议包含 inspect_session、spawn_test、grant_test_item、reset_test_arena 与 recover_reward，均需管理员权限；测试模式不能重复触发正式首胜。

**实际验收。** 胜利前断线、胜利后未领、背包满、领取中退出、正常停服重启、跨维度、迁移旧存档都需要记录结果。当前资料包仅定义这些检查，未进行模组运行验收。

# 29 动作适配与依赖锁定

建议保留可独立游玩的基础路线，优先验证 Better Combat + Combat Roll；Epic Fight 作为独立适配任务。三种模式互斥选择，同一普通攻击和躲避动作只有一个拥有者。不能因为它们都能安装，就称全套机制已兼容。[S4-S6]

| 路线 | 普攻 / 躲避 / 格挡的归属 | 本模组保留 |
| --- | --- | --- |
| A 原生基础 | 原版普攻；本模组短闪；原版盾 / 本模组持械格挡 | 五位机制、专注、姿态、装备主动与全部奖励 |
| B 推荐先测 | Better Combat 普攻；Combat Roll 翻滚；格挡按实际支持做桥接 | 关闭原生短闪，命中仅接外部成功事件，主动仍独立 |
| C Epic Fight | Epic Fight 普攻、体力、闪避与格挡，需实体 / 武器专门配置 | 关闭 B 与原生短闪；接入可验证的格挡事件，不能接入则取消该项挑战 |

**翻滚决定。** 基础版短闪无无敌帧即可完整通关。路线 B 的设计目标为约 3 格、一次充能、约 4 秒恢复；以实际 1.20.1 文件的可配置能力为准，不把当前主分支 README 的默认值当成旧版事实。无敌窗初版目标为 0，若短窗可配置再做独立平衡测试；翻滚使用外部资源，不再额外扣一份本模组专注。[S5]

**版本锁不猜。** VERSION_LOCK.md 记录每个实际 Jar 的文件名、MC 版本、加载器、版本、下载页、SHA-256、前置依赖与实测环境；验证成功前写 UNVERIFIED。GeckoLib / Curios 为核心正式依赖；动作模组可选，缺失时 A 正常启动。只有实测通过的组合进入推荐清单，不自动升级依赖解决一切问题。

**最先测什么。** 训练场一把剑、一枚单弹、一次盾挡、一次短闪 / 翻滚、一件 Curios 饰品；确认一击只扣一次血、精确格挡事件可用、服务器不加载客户端类，再把动作路线接到 Boss。自定义 Boss 能显示 Gecko 动画，不等于它自动获得 Epic Fight 正确战斗配置。

**冲突处理。** 同时安装 B 和 C 时，显示明确选择说明，默认禁用未选桥接；不静默叠加。外部模组更改视角或伤害系统时在诊断页列出实际模式。若出现重复扣血，先关闭可选桥接恢复基础模式，保留日志定位拥有权。

**发布说明的措辞。** “计划适配”“已启动”“功能手测通过”分别记录。当前阶段均为计划规格，尚未宣称 Better Combat、Combat Roll、Epic Fight 或任何整合包组合通过实测。1.21.11 移植另立版本锁与迁移分支，不在同一首发任务中混改。

# 30 验收标准与性能目标

设计是否成功，既看 Boss 有没有辨识度，也看普通玩家是否能在没有攻略与动作模组的情况下理解失败原因。每个阶段至少做一次“我被什么打中、下次怎么躲”的口述复盘；反馈答不出来，就先修预告和节奏。

| 验收组 | 必须得到的证据 |
| --- | --- |
| 基础工程 | clean build 成功日志；开发客户端与专用服务端启动记录；无客户端类加载崩溃 |
| 战斗判定 | 同一段一次伤害；锁向和实际范围匹配；格挡减伤不重复；阶段阈值只触发一次 |
| 五位机制 | 各自三个阶段、库存 / 条款 / 构件 / 挑战正确；每位都有无精准格挡解法 |
| 生存成长 | 从新世界原版采集做 T1；铁甲首战可尝试；碎片、核心保底、合成无卡死 |
| 沙盒与多人 | 前两页 20 场景；双人贡献、死亡返回、名单、退出、外场援助与重复包 |
| 存档与经济 | 满背包、重复领取、重启、断线、冷却与槽位去重；异常恢复有日志 |
| 动作与 HUD | 每条声明支持的模式单独验证；无双翻滚、双资源条或重复普攻伤害 |
| 视觉与音效 | 低特效仍读懂危险；色弱形状提示；震屏可关；主条与当前机制可见 |

**首战手测配置。** 无附魔铁甲、远征剑或测绘弓、盾、原版食物、少量箭与方块。先用走位 / 盾通关，再测精准格挡上限；分别测试原生与推荐动作路线。熟练者目标约 3-5 分钟，新手失败能明确指出哪一步没处理。

**性能预算是目标，不是已测结果。** 固定同一测试世界、渲染距离、硬件与依赖，记录无 Boss 基线与单场 / 两场并发。目标 20 TPS，单场增量服务端 tick 耗时中位数 <3ms、p95 <6ms；不是全服所有模组总耗时。战斗实体建议≤8 个机制实体，普通粒子客户端生成；采样至少 60 秒，不凭一瞬帧率截图下结论。

**需要自动化的高价值点。** 阶段跨阈值、一次命中去重、核心保底、配方扣料、奖励唯一键与请求重放。可用 Forge GameTest / 纯逻辑测试分层验证。动画观感、预告可读性和模组交互仍需实机，不写一堆只镜像实现的测试冒充可靠性。

**调试日志字段。** encounter_id、boss_id、phase、attack_instance_id、target、damage_owner、result、request_id。默认日志低频，调试时打开细节；不在玩家聊天框逐次打印伤害。每次修复保存最短复现与真实验证结果。

**发布门槛。** 五位机制、基础路线、生存成长与奖励存档是正式完整内容的必需项；动作路线、外围后三种小兵可单独标为预览。只完成 DeepSeek 时可发布明确标记的一 Boss 测试版，不能把计划表写成已有五 Boss。

# 31 分阶段开发与可接受降级

先完成能运行、能打赢、能拿奖励、能重启继续玩的最小闭环。每一阶段只做一个可验证目标；不要把整本设计交给 AI 后要求“一口气全实现”，否则最容易得到大量空壳类和看似完整的菜单。

| 里程碑 | 实际交付 | 通过后再做 |
| --- | --- | --- |
| M0 工程与依赖 | Java / Gradle / Forge 锁定；一个物品、一个测试实体；客户端与专用服务端启动 | Gecko 动画与 Curios 槽基本绑定，不能假写通过日志 |
| M1 战斗基座 | 远征剑、专注、格挡、短闪、姿态、一次可视时间线攻击、调试范围 | 原生单人 + 双人一击不重复；再评估 B 路线训练场 |
| M2 DeepSeek 垂直切片 | 一座最小祭坛、三阶段、转包退回、个人奖励、保底与工坊一把武器 | 正常失败 / 重试 / 重启闭环，通过后再美化岛屿 |
| M3 第二位 GPT | 复用共通框架，有限后手、额度卡、初次两槽解锁 | 检查架构是否真能扩第二位，不复制一套系统 |
| M4 Claude / Gemini / Grok | 逐位完成机制、三阶段、装备与精通，逐位验收 | 每位合入主线后再启下一位；资产可先用简化模型 |
| M5 世界与打磨 | 五处正式结构、前两种外围小兵、HUD / 声音、可读性与沙盒矩阵 | 锁发布清单；B 模式通过才列推荐，C 独立排期 |

**不能删的内容。** 一位 Boss 的普通攻防、至少两个可感知机制结果、三阶段变化、明确反击窗、掉落能力回流与可靠结算。若资源不足，先少做角色，不能保留五张漂亮模型却把五场战斗全变成挥砍。

**可以简化的内容。** 遗迹外围用原版方块、模型不做布料、P2 组合先固定、小兵先两种、无配音、剧情只短句、无新维度。Boss 强度与表现依靠调度、轮廓和声音，也能在有限资产下成立。

**实际安排。** 先把手感原型交给玩家试玩，记录能否走位躲掉、何时可反打，再投入角色精模。不要先做五套完整 UI 或十几种材料贴图。每完成一段验收再更新 PROGRESS 与版本锁，避免设计上完成等同代码已完成。

**AI 分工原则。** 更强的模型适合审查状态机、并发结算、动作桥接和疑难崩溃；可用的常规模型处理已定规格的局部实现、资源表和文案。无需为执行本方案再购买新会员；实际可选模型、额度与工具权限以现有账号当时显示为准。

**首轮明确不做。** 五 Boss 同时开工、Epic Fight 全适配、在线 AI 对话、玩家完整动作捕捉、可视化技能编辑器、全套装效果与终极联动 Boss。它们不阻挡首个完整可玩的 Boss。

# 32 Claude Code 与 GPT：同一工程接力

**可以接手，工程不需要重写。** Java 源码、Gradle 工程、模型与 JSON 不依赖由哪一个 AI 生成。换模型可能改变代码风格、理解范围与错误类型；固定接口、当前任务与同一套验证能降低影响，但不能保证质量完全一样。聊天历史与工具的内部检查点也不会自动跨平台共享。[S7-S9]

| 交接对象 | 固定文件 | 原则 |
| --- | --- | --- |
| 项目规则入口 | AGENTS.md；CLAUDE.md 导入 @AGENTS.md | 共用同一份短入口；避免两套相互矛盾规则 |
| 唯一规格 | docs/00_direction.md 至 docs/33_sources.md | 本版 v0.3 是当前基准，旧版不再并行决策 |
| 当前目标 | CURRENT_TASK.md | 一次一个任务、范围、完成条件、允许改动目录 |
| 真实状态 | PROGRESS.md、HANDOFF.md | 完成 / 未完成 / 未运行分别写，记最后通过的命令与提交 |
| 依赖与决策 | VERSION_LOCK.md、docs/DECISIONS.md | 不因模型切换更换 MC 版本、加载器、库或架构 |
| 缺陷与资产 | KNOWN_ISSUES.md、references/manifest.json | 保留复现与来源；模型不能想当然重画角色 |

**入口文件的依据。** Codex 官方支持从项目路径读取 AGENTS.md；Claude Code 当前文档支持 CLAUDE.md，也说明了 AGENTS.md 与 @AGENTS.md 导入方式。本方案保留导入文件以照顾不同客户端 / 版本，开工时实际确认加载了哪些规则。[S7,S8]

**正常切换。** 结束本次最小任务，保存全部文件；检查 git status / diff，记录用户原有修改；完成有意义的验证；写清当前失败与下一步；可用时建立明确的 WIP 提交。交给 GPT 的是同一工作区或同一 Git 提交加未提交差异，不仅是一句“继续上次”。回到 Claude 时按同样流程接回。

**不是同时抢文件。** 当前只启用一个编辑者；另一个如需阅读审查可只读。没有 Git 时先做带时间戳的完整工程快照，不把 Claude 内部 rewind 当作跨工具版本控制。[S9] 不为了清理工作区执行破坏用户改动的强制重置。

**GPT 工具条件。** 优先用能读写同一工程并运行命令的 Codex / 编码环境。普通 ChatGPT 聊天若不能直接访问目录，就需要提供相关文件、版本锁与差异，让它给补丁，再由本地执行与验证；不能声称它已经在看本机所有文件。两边账号可用额度分别看，不承诺一个会员会补另一个额度。

**预算边界。** 不自动切到计费 API、不购买额外额度、不把密钥放进工程。额度不足就停止新生成，把现有文件作为接续点；已有代码和素材不会随额度耗尽消失。

# 33 突然没额度：恢复流程与首个任务

**最坏情况也能接。** Claude 在半个方法或编译失败时突然停止，不等它恢复额度来补总结。以磁盘、Git 差异和真实日志为准，GPT 先做状态核对，再沿原任务完成最小修复；不要推翻项目重新生成。

| 顺序 | GPT / Codex 接手动作 | 留下的证据 |
| --- | --- | --- |
| 1 接收 | 读 AGENTS、CURRENT_TASK、HANDOFF、VERSION_LOCK，定位当前工程 | 简短列明目标、已知状态与待核验项 |
| 2 对照 | 读 git status、diff、最近提交；找半成品、冲突标记与用户改动 | 改动文件清单；不把原有修改覆盖 |
| 3 复现 | 先运行最后记录的失败命令；无记录则从对应最小构建开始 | 实际命令、退出状态、首个根因；缺环境就写明 |
| 4 收口 | 只修当前任务必需部分；不顺便重命名全部模块或升级依赖 | 最小可审查差异；必要设计变化写 DECISIONS |
| 5 验证 | 运行相同构建与相关手测；更新状态，必要时留 WIP 快照 | 真实通过 / 失败 / 未运行，不编造测试结果 |

**切换边界。** 已通过检查的模块保持接口；新发现规格冲突以本版统一稿和最新用户决定为准，并记录原因。模型对机制理解不同，先对照状态表、阈值与参数，不靠重新写“自己的更好版本”消除差异。

**启动提示词，适用于两边。** “你正在接手《调用者 · 协议裂隙》Minecraft 1.20.1 Forge 模组。先读 AGENTS.md 和其中指定文件，以当前磁盘与 Git 为准。只完成 CURRENT_TASK.md 的一个目标，保留用户改动；不升级依赖、不改角色机制、不同时实现五 Boss。先复现记录的问题，再做最小实现并真实运行相关验证；结束更新 PROGRESS、HANDOFF 与实际失败项。无法运行请写原因，不得用推测写通过。”

**本包的当前状态必须诚实。** 当前为 DESIGN_ONLY，尚无 Java / Gradle 模组工程、没有通过的编译、没有通过的客户端 / 服务端实测，也没有真实开发提交号。模板中的未知项均写 UNSET / NOT_RUN，不能自动补成“全部完成”。

**首个实际任务 M0-01。** 在新的工程目录建立 Forge 1.20.1 最小项目与版本锁，注册一个旅人剑物品和一个简单测试实体；接入 GeckoLib 的最小空闲动画与 Curios 的单个专用槽。只要求 build、开发客户端、专用服务端三个检查，并记录依赖文件。若环境无法启动图形客户端，构建和服务端先完成，客户端明确留待本地验证；不要提前实现 Boss 机制。

**开工前后的文件分工。** 开工包中的文档与参考图可以直接搬入工程；Gradle 包装器、源码、正式模型和实际锁定配置由 M0 建立。开发资料包内没有可安装 Jar，也没有需要玩家填写的 AI 服务账号配置。
